COMMIT or ROLLBACK inside a loop (slow, breaks atomicity, ORA-01555 risk).

Example:

FOR r IN c LOOP
  UPDATE t SET x = r.x WHERE id = r.id;
  COMMIT;
END LOOP;

Better:

FOR r IN c LOOP
  UPDATE t SET x = r.x WHERE id = r.id;
END LOOP;
COMMIT;

Suppress on one line with -- noqa: PLL003, or for a whole file with -- plsql-lint: disable-file=PLL003 (the same comments work with the plsql-lint command-line tool).
