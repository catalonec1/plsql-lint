UPDATE or DELETE without a WHERE clause changes every row.

Pro check. Requires a PL/SQL Lint Pro licence or the free trial; without it this inspection reports nothing.

Example:

DELETE FROM orders;

Better:

DELETE FROM orders WHERE created < ADD_MONTHS(SYSDATE, -24);

Suppress on one line with -- noqa: PLL020, or for a whole file with -- plsql-lint: disable-file=PLL020 (the same comments work with the plsql-lint command-line tool).
