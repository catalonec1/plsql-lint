Named END without the unit name (END; instead of END my_proc;).

Example:

CREATE OR REPLACE PROCEDURE do_it IS
BEGIN
  NULL;
END;
/

Better:

CREATE OR REPLACE PROCEDURE do_it IS
BEGIN
  NULL;
END do_it;
/

Suppress on one line with -- noqa: PLL011, or for a whole file with -- plsql-lint: disable-file=PLL011 (the same comments work with the plsql-lint command-line tool).
