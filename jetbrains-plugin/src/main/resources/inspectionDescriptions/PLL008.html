ROWNUM filter combined with ORDER BY in the same query (filter runs first).

Example:

SELECT id FROM t WHERE ROWNUM <= 10 ORDER BY created DESC;

Better:

SELECT id FROM t ORDER BY created DESC FETCH FIRST 10 ROWS ONLY;

Suppress on one line with -- noqa: PLL008, or for a whole file with -- plsql-lint: disable-file=PLL008 (the same comments work with the plsql-lint command-line tool).
