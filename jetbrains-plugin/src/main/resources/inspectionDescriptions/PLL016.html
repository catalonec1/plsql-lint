SELECT COUNT(*) INTO used to test existence; counts every row.

Pro check. Requires a PL/SQL Lint Pro licence or the free trial; without it this inspection reports nothing.

Example:

SELECT COUNT(*) INTO l_cnt FROM orders WHERE customer_id = p_id;
IF l_cnt > 0 THEN

Better:

SELECT COUNT(*) INTO l_cnt FROM orders
 WHERE customer_id = p_id AND ROWNUM = 1;
IF l_cnt > 0 THEN

Suppress on one line with -- noqa: PLL016, or for a whole file with -- plsql-lint: disable-file=PLL016 (the same comments work with the plsql-lint command-line tool).
