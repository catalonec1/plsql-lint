NOT IN (SELECT ...) returns no rows when the subquery yields a NULL; prefer NOT EXISTS.

Example:

WHERE id NOT IN (SELECT parent_id FROM t)

Better:

WHERE NOT EXISTS (SELECT 1 FROM t WHERE t.parent_id = x.id)
