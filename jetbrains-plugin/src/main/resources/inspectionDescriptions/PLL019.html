Password written in source with IDENTIFIED BY.

Pro check. Requires a PL/SQL Lint Pro licence or the free trial; without it this inspection reports nothing.

Example:

CREATE USER app IDENTIFIED BY "Secret123";

Better:

CREATE USER app IDENTIFIED BY &app_password;

Suppress on one line with -- noqa: PLL019, or for a whole file with -- plsql-lint: disable-file=PLL019 (the same comments work with the plsql-lint command-line tool).
