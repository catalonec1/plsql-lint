INSERT/UPDATE/DELETE/MERGE inside a cursor FOR loop (slow-by-slow); use BULK COLLECT + FORALL.

Pro check. Requires a PL/SQL Lint Pro licence or the free trial; without it this inspection reports nothing.

Example:

FOR r IN (SELECT id FROM orders WHERE status = 'OPEN') LOOP
  UPDATE orders SET status = 'CLOSED' WHERE id = r.id;
END LOOP;

Better:

UPDATE orders SET status = 'CLOSED' WHERE status = 'OPEN';
-- or BULK COLLECT ... LIMIT 1000 + FORALL

Suppress on one line with -- noqa: PLL017, or for a whole file with -- plsql-lint: disable-file=PLL017 (the same comments work with the plsql-lint command-line tool).
