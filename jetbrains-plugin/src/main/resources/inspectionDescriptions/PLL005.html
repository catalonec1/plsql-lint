Dynamic SQL built by concatenation (SQL injection risk, no plan reuse).

Example:

EXECUTE IMMEDIATE 'DELETE FROM t WHERE id = ' || p_id;

Better:

EXECUTE IMMEDIATE 'DELETE FROM t WHERE id = :1' USING p_id;

Suppress on one line with -- noqa: PLL005, or for a whole file with -- plsql-lint: disable-file=PLL005 (the same comments work with the plsql-lint command-line tool).
