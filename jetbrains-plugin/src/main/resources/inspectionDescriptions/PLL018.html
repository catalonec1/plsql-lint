AUTONOMOUS_TRANSACTION unit with DML but no COMMIT/ROLLBACK (ORA-06519).

Pro check. Requires a PL/SQL Lint Pro licence or the free trial; without it this inspection reports nothing.

Example:

PROCEDURE log_it(p VARCHAR2) IS
  PRAGMA AUTONOMOUS_TRANSACTION;
BEGIN
  INSERT INTO app_log VALUES (SYSTIMESTAMP, p);
END;

Better:

PROCEDURE log_it(p VARCHAR2) IS
  PRAGMA AUTONOMOUS_TRANSACTION;
BEGIN
  INSERT INTO app_log VALUES (SYSTIMESTAMP, p);
  COMMIT;
END;

Suppress on one line with -- noqa: PLL018, or for a whole file with -- plsql-lint: disable-file=PLL018 (the same comments work with the plsql-lint command-line tool).
