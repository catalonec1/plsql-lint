TO_DATE / TO_TIMESTAMP without a format mask depends on NLS settings.

Example:

l_d := TO_DATE(p_text);

Better:

l_d := TO_DATE(p_text, 'YYYY-MM-DD');

Suppress on one line with -- noqa: PLL015, or for a whole file with -- plsql-lint: disable-file=PLL015 (the same comments work with the plsql-lint command-line tool).
