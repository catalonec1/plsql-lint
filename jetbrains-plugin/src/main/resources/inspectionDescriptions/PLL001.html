WHEN OTHERS handler that does not re-raise the error.

Example:

BEGIN
  process;
EXCEPTION
  WHEN OTHERS THEN NULL;
END;

Better:

BEGIN
  process;
EXCEPTION
  WHEN OTHERS THEN
    log_error(SQLERRM);
    RAISE;
END;

Suppress on one line with -- noqa: PLL001, or for a whole file with -- plsql-lint: disable-file=PLL001 (the same comments work with the plsql-lint command-line tool).
