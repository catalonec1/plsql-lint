RAISE_APPLICATION_ERROR number outside -20000..-20999 (raises ORA-21000).

Example:

RAISE_APPLICATION_ERROR(-30001, 'bad input');

Better:

RAISE_APPLICATION_ERROR(-20001, 'bad input');

Suppress on one line with -- noqa: PLL010, or for a whole file with -- plsql-lint: disable-file=PLL010 (the same comments work with the plsql-lint command-line tool).
